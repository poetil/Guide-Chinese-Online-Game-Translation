# English Translation using melonLoader & XUnity.AutoTranslator Mod
This guide provides a comprehensive walkthrough for implementing a real-time English Translation using MelonLoader & XUnity.AutoTranslator. We focus on breaking down the technical setup to help you bypass language barriers in games that lack official localization, covering everything from initial plugin injection to fine-tuning translation engines
# 1. Installing MelonLoader
you can see how to install in [official website MelonLoader](https://melonwiki.xyz/)
# 2. Adding XUnity.AutoTranslator Mod
## Download XUnity.AutoTranslator

download XUnity.AutoTranslator in this github page
[https://github.com/bbepis/XUnity.AutoTranslator](https://github.com/bbepis/XUnity.AutoTranslator)

Choose the latest release

Download MelonLoader (IL2CPP Version)

download melonLoader version with ***il2cpp***

![Screenshot 2026-04-14 203035](Screenshot%202026-04-14%20203035.png)

extract zip file in game folder

# 3. Config XUnity.AutoTranslator Mod
- open the game wait a moment for melonLoader patching and create config for the game
- close the game
- open auto translator config in "<gameFolder>/AutoTranslator/Config.ini"
- change "**FromLanguage**" to "**zh**"
- Reopen the game and **ENJOY**
